はじめて使うとき・トラブルシューティング
  1. この HTML ファイルを、デスクトップ版の Chrome または Edge で開きます。
  2. P12 Pro の電源を入れ、Windows の Bluetooth 設定でペアリングします。
  3. 「Bluetooth 接続」から P12Pro またはその送信 COM ポートを選びます。COM 番号は PC ごとに異なります。
  4. プレビューを確認して「印刷する」を押します。最初は 1 枚で仕上がりを確認してください。

Firefox・Safari・iPhone/iPad のブラウザは、このツールの直接印刷には対応していません。プレビューや PNG 保存は利用できます。BLE は機種・OS によって使えない場合があります。

「開けませんでした」の場合は、他の印刷アプリを閉じ、送信側のポートを選び直してください。テープ切れ、カバーの状態、電源も確認してください。通信途中で失敗した場合は、プリンターの電源を入れ直してから再接続してください。自動再送はしません。

USB 接続・OS の通常の印刷ダイアログは使いません。画面上の「送信完了」は実機の印刷完了を保証しません。画像は自動保存されないため、残す場合は「デザイン保存」を使用してください。

照会応答には機器の製造番号などが含まれる場合があります。
通信仕様の参照：phomemo_p12 / Phomymo。メーカー公式ツールではありません。
